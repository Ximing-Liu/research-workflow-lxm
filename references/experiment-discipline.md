# 实验阶段的三件事

Agent 在这一阶段是主力——写代码、调参、跑训练、画图，这些交出去没问题。
但有三件事人不能交，交了就会失控。

## 一、verify：结构和中间过程都要看

现在这一批模型有个共同特点：**很快，也很莽。**给一个方向就往前迈一大步，
不等你确认。走着走着你会发现看不懂它在干什么了——因为它解释用的术语是它自己发明的。

### verify 结构

它做完第一版之后，回过头看当前代码的**主要结构和思想**。

不用看得很细——细节它确实做得很好——**但你必须知道它在干什么**。
判断标准很简单：**你能不能用自己的话跟别人讲清楚这段代码的思路。**讲不清楚就是没懂。

### verify 中间过程（更重要，也更容易被跳过）

这一步不一定要看代码，**用问的**：

- 输入是什么形状、怎么预处理的
- 输出是什么、怎么转成最终指标的
- 数据是怎么切的、split 的依据是什么
- 这个 loss 具体在惩罚什么

**逐块问，然后配合代码对一遍。**大概率会发现某几步和你想的不一样——
不是大错，是那种"能跑通但语义不对"的小偏差。这类问题**只有对着中间过程问才能发现**，
看最终指标看不出来（指标看起来很正常）。

> 这一步的成本是慢。收益是不会失控。
> 急着完成一件事的代价通常在两周后以技术债的形式出现，那时候已经拆不动了。

## 二、每一版都要命名、都要留着

一篇文章往往要迭代八九版，甚至十几版。没有版本记录的话，
三周后你会想不起来"当时那个 0.89 是哪个配置跑出来的"。

`experiment/results.md` 里一版一行，**不覆盖、不删**，包括失败的和作废的。

### 命名

```
v<序号>_<改动的核心>
```

- 序号连续不跳号
- 改动用领域里已有的词，不要自造
- **禁止** `test`、`test2`、`final`、`final_v2`、`new`、`backup`、拿日期当名字

### 版本表长这样

| 版本 | 改了什么 | 主指标 | 副指标 | 结论 |
|---|---|---|---|---|
| v1 | 固定 baseline | 0.7501 | 0.6890 | 基准线 |
| v2 | Oracle 上界 | 0.9612 | 0.8455 | 天花板，说明有 21 个点可捞 |
| v3 | 随机对照 | 0.7488 | 0.6902 | 和 v1 持平 → 收益来自"选对"不是"多样性" |
| v4 | 加了核心模块 | ~~0.9821~~ | ~~0.9103~~ | ❌ 作废：数据泄漏 |
| v5 | v4 修掉泄漏 | 0.8447 | 0.7215 | 真实水平 |

**v2 和 v3 这两行很关键。**只有 v1 和 v5 的话，你不知道 0.84 算好还是不好；
有了上界和随机对照，这个数字才有意义。**设计实验时就把这两个参照系排进去。**

## 三、测评标准化

`experiment/evaluation.md` 写死四件事：

1. **用什么数据**：训练用哪个、测试用哪个、split 依据是什么
2. **报哪些指标**：全部列出来，**包括你表现不好的那些**
3. **出哪些可视化**：固定住，每次都出，不管这版结果好不好
4. **输出到哪**：文件名和目录结构

写完之后，一句「用标准化测评测一下 v8」就够了，不用每次重新交代。

**这份文档真正的作用是防止 cherry-pick。**人在看到"这版某个指标特别好"的时候，
会不自觉地只报那个指标。写死了就不会。

### 可视化里最有用的是失败样例

除了量化指标，**固定抽 5–10 条失败样例**，每次实验都出同一批。

量化指标告诉你好不好，**失败样例告诉你为什么**。而且固定住之后可以跨版本对比——
"上一版这条错的，这一版对了"，这个信息量比 AUROC 涨了 0.01 大得多。

做生成类任务的话，同理：固定几个 prompt，每次都出，看质量的演进。

## 数据泄漏：突然变好要先查这个

**任何一版效果突然暴涨，第一反应是查泄漏，不是庆祝。**

最常见的几种：

| 症状 | 查什么 |
|---|---|
| 效果好得不真实 | **split 是按样本分的还是按类别/来源/被试分的**？按样本分几乎必然泄漏 |
| 训练集和测试集来自同一批生成/同一批采集 | 同一条数据的不同增强版本可能分散在两边 |
| 用了预训练模型 | 预训练语料是否已经包含测试集 |
| 特征里有 ID、时间戳、文件名 | 模型可能在学"我见过这条"而不是任务本身 |

**split 的正确做法通常是按"你希望模型泛化的那个维度"来分。**
希望它泛化到没见过的模型/被试/域，就按模型/被试/域分，不是按样本分。

这个错误在文献里非常普遍，而且一旦发生，后续所有版本的数字都不能用。
**修完要把作废的版本留在 results.md 里并标注原因**——那是你自己后来复盘的依据，
也是写论文时 limitation 部分的素材。
